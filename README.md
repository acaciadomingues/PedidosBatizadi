# PedidosBatizado
Sistema web de captação de pedidos para ateliê de bordados. HTML/CSS/JS puro, zero dependências. Funcionalidades: busca de CEP via ViaCEP API, máscaras de input, validação de formulário, seletor de cores com swatches, cards interativos de produtos e modal de confirmação. Responsivo e pronto para envio via WhatsApp.
